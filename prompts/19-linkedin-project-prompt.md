# 19 — LinkedIn Project Description Prompt

**Use when:** writing a shareable project post/summary.

## Role
Concise professional writer, not a marketer.

## Context to Read
The final `README.md` and `PROJECT_STATUS.md`.

## Objective
A short (roughly 150–250 word), professional description: what the project is, the problem it addresses, the technical approach, and 2–3 concrete things that make it more than a tutorial project (e.g., the explainable congestion scoring, the tracker abstraction, the honest simulation labeling).

## Rules
No invented metrics. No claiming production/live deployment if it's a portfolio project. Simulated features stay labeled as such if mentioned.

## Expected Output
One ready-to-post LinkedIn description.

## Restrictions
Don't pad with buzzwords not backed by something actually in the repo.

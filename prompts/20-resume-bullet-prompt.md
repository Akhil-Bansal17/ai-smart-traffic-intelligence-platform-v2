# 20 — Resume Bullet Prompt

**Use when:** producing resume-ready bullet points.

## Role
Resume writer who only uses verifiable claims.

## Context to Read
`PROJECT_STATUS.md`, `README.md`, actual test/eval results if quantifying anything.

## Objective
3–4 bullets, each: strong action verb, specific technical detail, and (only if actually measured) a real number.

## Rules
- Never invent a metric (accuracy %, latency, throughput) that wasn't actually measured.
- If nothing was measured for a claim, phrase it around scope/architecture instead of a fabricated number (e.g., "designed a modular CV pipeline supporting swappable trackers" rather than a made-up accuracy figure).

## Expected Output
3–4 bullets ready to paste into a resume.

## Restrictions
No percentage improvement, speed number, or accuracy figure without a cited source in this repo's own eval output.

# 21 — Interview Preparation Prompt

**Use when:** preparing to discuss this project in an interview.

## Role
Interview coach who also stress-tests technical depth.

## Context to Read
`ARCHITECTURE.md`, `PROJECT_STATUS.md`, the actual code for whatever area is being prepped.

## Coverage Areas
YOLO/object detection, object tracking (ByteTrack/BoT-SORT), general CV concepts, traffic density/congestion scoring methodology, ML fundamentals used here, feature engineering choices made, time-series prediction validity (leakage, validation strategy), FastAPI design choices, React/frontend architecture, PostgreSQL schema decisions, system architecture tradeoffs, security measures taken, and — importantly — this project's actual limitations.

## Workflow
1. Generate likely interview questions per area above.
2. For each, write a real answer grounded in what was actually built (pull from `ARCHITECTURE.md`/code, don't generalize).
3. Include at least a few "why did you choose X over Y" questions, since those test understanding, not memorization.
4. Include a "what would you improve" question per area — a good answer here is a strength, not a weakness.

## Expected Output
A Q&A set organized by topic area.

## Restrictions
Don't write an answer that claims a capability the project doesn't actually have.
